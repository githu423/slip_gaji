EXCEL SLIP GAJI
Baru pertama kali? Lihat panduan singkat.+

1. Siapkan file Excel

Gunakan template agar nama kolom sesuai. Isi Nama dan Gaji Pokok dengan nominal angka, tanpa “Rp”. Data dibaca dari lembar pertama.

2. Tambahkan komponen gaji

Kolom berawalan “Tunjangan” ditambahkan ke pendapatan. Kolom berawalan “Potongan” dikurangkan untuk menghitung gaji bersih.

3. Pilih cara mengunduh

Unduh per pegawai atau sekaligus. Word menghasilkan satu dokumen dengan halaman terpisah; PDF dikemas dalam satu file ZIP.
